# V4 reconstruction

V4 creates V3 token dictionaries, classifies each using clause/sentence
windows, and masks spans classified as `REJECTED_PREMISE`. It then delegates a
new masked claim to the frozen V3 validator. The decision is therefore
temporary span masking, but role discovery is still based on token kind/unit,
same-kind companion presence, and clause text.

The V4 helper has no immutable occurrence ledger. In particular, it has no
stable identifier joining a role decision to the exact token that the value
validator will later inspect. Its same-kind companion check also explicitly
requires a different normalized value. Equal-value siblings therefore do not
form the corrective pair needed by C50-style cases. That explains the V4
same-value multi-occurrence failure as `VALUE_LEVEL_COLLAPSE` combined with
`CLAIM_ASSOCIATION_LOSS`: the model has separate spans, but the role contract
does not carry separate identities through to validation.

The first unrecoverable point is **ROLE CLASSIFICATION** for equal-value
siblings. The later mask is span-based, but it cannot fix a role that was
never assigned to the correct occurrence.
