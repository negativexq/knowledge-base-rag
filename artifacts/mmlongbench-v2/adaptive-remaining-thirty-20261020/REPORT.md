## Manual checks overriding or completing automatic review

- **510:** original geographic-market page 7 shows Jackson and Northern Mississippi
  as two Mississippi market entries, but no Oxford label or source-grounded Oxford
  location. The collector infers Oxford is inside the northern region and counts
  one. Neither the transcription nor the map establishes that requested entity
  binding. The result is not certified despite accepted input review.
- **638:** original physical page 5 is printed 6985. Its Figure 2 program example
  is at the top; the lower Figure 3 is a QA implementation diagram. Runtime counts
  one complete example from Figure 2, ignoring the question's bottom-of-page
  constraint. Automatic after-run review has no reference images and also misses
  the location constraint. Its approval is overridden.
- **834:** original full-year assignment-summary pages 15–16 show the three named
  case studies in Quarters 1–2 and no additional Critical Thinking Case Study in
  Quarters 3–4. This closes the automatic review's missing later-quarter check.
- **1075:** the original balance-sheet page already audited in the preceding batch
  contains current long-term debt 16, noncurrent debt 1160 and equity 2795. The
  released 29.3% explicitly excludes the current portion. Including it produces
  29.6%, matching the reference. The question does not specify the definition;
  arithmetic approval cannot settle that choice, so the row remains open.
- **636:** automatic review proposes K=20, but examples used for prompting and
  examples visibly shown in the main body are distinct targets. That alternative
  is not certified as the answer to this question.

## Recurring failure mechanisms

Correct values can be found but not released: missing unit/header context, grouped
number notation, output-unit conversion and unsuccessful input repair recur in
380, 1016, 1072 and 1074. Row 214 retains a supported calculation yet cannot resolve
a faulty premise. Row 641 loses the relation between a comparison graph and a
separate answer table; 1017 fails to consume a required lease-note source.

Whole-document visual inventories 662/663 remain hard under bounded page windows;
coverage must accumulate across windows rather than imply the current pages are
the whole inventory. Visual ordering in 393 and location in 638 show distinct
selection and final-scope failures. Numeric-only contracts also remain a poor
match for text-in-box tasks such as 520.

Negative questions often spend several tool calls revisiting an incompatible
entity/date or unavailable operand. A source-scoped mismatch, incomplete search,
unsupported numeric result and model/API/schema error need separate terminal
states. This report does not turn no-progress or tool-budget exhaustion into
proof that an object is absent.

Survey headcounts 216/219 require population and approximation semantics, not
only arithmetic. An 18% Democratic value cannot silently borrow a Dem/Lean Dem
base; rounded weighted percentages do not establish exact observed headcounts.
